# 우주 방어

브라우저에서 좌우 이동·사격·회피로 내려오는 적 편대를 막는 게임 제작 실습입니다.

## 현재 상태

현재는 개발 문서를 준비하는 단계입니다. 게임 코드·의존성 manifest·실행 명령은 아직 없으며, 설치·게임 실행·화면 검증은 수행하지 않았습니다.

문서 준비와 게임 구현·배포 완료는 다릅니다. 구현 전에는 PRD 기준표의 미정 값을 확정해야 합니다. 정확한 동시 사건의 화면 재현 가능성도 아직 미확인이며, 관련 검증 조건은 유지합니다.

## 문서 읽기 순서

| 문서 | 역할 |
|---|---|
| [ideation.md](ideation.md) | 대상 사용자, 선택 배경과 핵심 경험 |
| [PRD.md](PRD.md) | 제품 규칙·수치의 단일 기준, 지원 범위와 수용 조건 |
| [TRD.md](TRD.md) | 기술 선택, 모델/UI 책임과 구현·검증 경로 |
| [AGENTS.md](AGENTS.md) | 에이전트의 사용자 작업·비밀 보호와 승인 경계 |

실습 참가자는 아이디어 → 제품 요구사항 → 기술 설계 순으로 읽습니다. 에이전트는 파일을 변경하기 전에 AGENTS.md와 관련 문서를 먼저 확인합니다.

## 구현과 실행 준비

다음 단계는 미정 제품 값 확정과 별도 승인된 구현 작업입니다. 의존성과 실행·검사 명령은 TRD의 준비 순서에 따라 manifest에서 정의합니다. 실제로 확인한 준비 환경·실행 방법은 구현 후 이 문서에 추가합니다.

지금은 실행할 앱이 없으므로 설치·실행 명령을 안내하지 않습니다. 게임 규칙과 제품 수치는 PRD를 참조하며 이 문서에 중복하지 않습니다.
